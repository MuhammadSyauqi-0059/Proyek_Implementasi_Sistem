Penelitian ini berfokus pada perancangan website pemetaan petani dan UMKM kopi berbasis web untuk meningkatkan eksposur kopi lokal Pekalongan. Website dirancang bersifat informatif, menampilkan lokasi, profil, dan produk kopi, serta diposisikan sebagai pilot project dengan arsitektur scalable menuju skala nasional. Evaluasi dilakukan dengan blackbox testing dan System Usability Scale (SUS)
